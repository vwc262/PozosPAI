### How-To

The shader incorporates a number of features that can be customized to your liking. Here is a quick guide on how to use the shader:

1. **Create a new material**: Right-click in the Project window, select `Create > Material`, and name it whatever you like.
2. **Assign the shader**: Select the material you created, and in the Inspector window, click on the Shader dropdown menu. Navigate to `HDRP Ultimate Glass Shader` and select it.
3. **Tweak the settings**: The shader has a number of customizable settings that can be adjusted to achieve the desired look. Play around with the settings to see how they affect the material.
4. **Apply the material**: Drag and drop the material onto the object you want to apply it to. You should now see the glass material on the object.
5. **Fine-tune the material**: If you want to make further adjustments, you can go back to the material settings and tweak them until you are satisfied with the result.
6. **Enjoy your realistic glass material!**

#### The shader features the following customizable settings:
- **Base Color**: The color of the glass material.
- **Transparency**: The transparency of the glass material.
- **Smoothness**: The smoothness of the glass material.
- **Metallic**: The metallic properties of the glass material.
- **Normal Map**: A normal map to add surface detail to the glass material. Note that this is interconnected with parallax map.
- **Parallax Map**: A parallax map to add depth to the glass material. Note that this is interconnected with normal map.
- **Refraction**: The refraction properties of the glass material. This incorporates the refraction map, refraction strength, and a secondary layer of refraction to mimic thickness.
- **Gradient Map**: A gradient map to add color variation to the glass material. One of the best use cases is to darken certain parts of the glass for example, namely the bottom part.
